# LinkedList
> Linear DS

>Unlike arrays elements are not stored in contiguous location

>Each Node stores the data and address of the node

**Advantage of using Linked List over arrays**

1. Faster insertion and deletion than arrays

**Drawbacks of LL**

1. Random acces not allowed so no Binary Search
2. Extra memory space required for storing address.
3. _*Not cache-friendly*_ Since array elements are contiguous locations, there is the locality of reference which is not there in the case of linked lists.
4. Direct access to an element is not possible in a linked list as in an array by index
5. Searching for an element is costly and requires O(n) time complexity.
6. Sorting of linked lists is very complex and costly.
7. Appending an element to a linked list is a costly operation, and takes O(n) time, where n is the number of elements in the linked list, as compared to arrays that take O(1) time.

**Types of LL**

1. Singly LL
2. Doubly LL
3. Circular LL
4. Doubly Circular LL
